# AI Meet

افزونه کروم/اج برای ضبط رونوشت زنده جلسات Google Meet (فارسی و چندزبانه)، خلاصه‌سازی هوشمند با چند ارائه‌دهنده AI قابل‌انتخاب (Gemini، OpenAI، Cloudflare AI Gateway، هر Endpoint سازگار با OpenAI مثل Ollama)، ذخیره تاریخچه در IndexedDB، خروجی PDF/Word/TXT/Markdown و همگام‌سازی اختیاری با یک ریپازیتوری GitHub شخصی کاربر.

## ساختار پروژه

```
manifest.json
src/
  db/            مدل‌ها و لایه ذخیره‌سازی IndexedDB
  ai/            رابط Provider ها + پیاده‌سازی هرکدام + کتابخانه قالب‌های پرامپت
  background/    Service Worker، ارکستریشن خلاصه‌سازی، همگام‌سازی گیت‌هاب
  content/       اسکریپت خواندن زیرنویس زنده داخل تب Google Meet
  export/        خروجی‌گیری PDF / Word / TXT / Markdown
  ui/            پنل کناری (Side Panel) و صفحه تنظیمات (Options)
assets/
  icons/         آیکون‌های افزونه (باید خودتان PNG سایز 16/48/128 اضافه کنید)
  fonts/         در صورت نیاز به حالت کاملاً آفلاین، فایل‌های Vazirmatn woff2 را اینجا قرار دهید
```

## نصب برای توسعه (Unpacked)

1. مخزن را کلون کنید.
2. آیکون‌های 16x16، 48x48 و 128x128 پیکسل PNG را داخل `assets/icons/` قرار دهید (نام‌ها: icon16.png، icon48.png، icon128.png). بدون آن‌ها افزونه با آیکون پیش‌فرض مرورگر بالا می‌آید و مشکلی در اجرا ایجاد نمی‌شود.
3. در Chrome یا Edge به آدرس `chrome://extensions` یا `edge://extensions` بروید.
4. حالت Developer mode را فعال کنید.
5. روی «Load unpacked» کلیک کرده و پوشه پروژه را انتخاب کنید.
6. وارد تنظیمات افزونه (Options) شوید و حداقل یک Provider هوش مصنوعی (مثلاً Gemini) را با کلید خودتان اضافه کنید.

## نکته مهم درباره زیرنویس زنده Google Meet

Google Meet زیرنویس زنده رایگان به زبان «Farsi (beta)» را برای همه کاربران پشتیبانی می‌کند. افزونه سعی می‌کند زبان زیرنویس را طبق تنظیمات شما به‌صورت خودکار در منوی Meet انتخاب کند؛ اگر ساختار DOM گوگل میت تغییر کند (که هر چند وقت یک‌بار رخ می‌دهد)، ممکن است نیاز به به‌روزرسانی سلکتورها در `src/content/meet-capture.js` باشد. در این حالت، کاربر همیشه می‌تواند زبان زیرنویس را دستی از منوی Meet انتخاب کند؛ افزونه به‌محض تشخیص متن روی صفحه، بدون توجه به این‌که خودکار یا دستی انتخاب شده، آن را ثبت می‌کند.

## حریم خصوصی و امنیت

کلیدهای API فقط در `chrome.storage.local` همان مرورگر کاربر ذخیره می‌شوند و هیچ‌گاه به سروری غیر از همان ارائه‌دهنده انتخابی (یا مخزن گیت‌هاب خود کاربر برای همگام‌سازی) ارسال نمی‌شوند. متن رونوشت هم به‌صورت پیش‌فرض فقط لوکال (IndexedDB) نگه داشته می‌شود؛ ارسال به AI یا گیت‌هاب کاملاً اختیاری و به انتخاب کاربر است.
