⚙️ تنظیمات AI Meet

Providerهای هوش مصنوعی

می‌توانید چند Provider تعریف کنید (Gemini، OpenAI، Cloudflare AI Gateway، یا حالت «بدون کلید») و هرکدام را برای جلسات مختلف انتخاب کنید. کلید API فقط در همین دستگاه ذخیره می‌شود.

قالب پرامپت پیش‌فرض

برای هر جلسه می‌توانید قالب را عوض کنید؛ این فقط پیش‌فرض ابتدایی است.

زبان جلسه

توجه: زبان زیرنویس زنده باید از داخل Google Meet روی همان زبان تنظیم شود (Settings > Captions).

تنظیمات خروجی

پیش‌فرض خاموش است - یعنی این چهار خروجی فقط شامل خلاصه، تصمیمات، اقدامات و تحلیل پیشرفته می‌شوند، نه رونوشت کامل جلسه.

همگام‌سازی با GitHub

توکن باید دسترسی Contents: Read and write روی مخزن مقصد داشته باشد (Fine-grained PAT پیشنهاد می‌شود). توجه: فایل جدای transcript.txt که در گیت‌هاب ذخیره می‌شود، همیشه رونوشت کامل را دارد و تابع تنظیم بالا نیست - آن یک نسخه پشتیبان کامل جداست.
